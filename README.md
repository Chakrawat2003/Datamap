# PinMap v3 — Realtime Shared Map

## ใหม่: ชั้นข้อมูลร้าน 7-Eleven (ฝังในตัวแอป)
- ไฟล์ `seven11-data.js` เก็บรายชื่อ/พิกัดร้าน 7-Eleven **18,482 สาขา** (แปลงจากไฟล์ CSV ที่ให้มา) โหลดพร้อมหน้าเว็บ ไม่ต้องพึ่ง Supabase หรือห้องใดๆ
- เปิดแผนที่ขึ้นมาจะเห็นหมุดร้าน 7-Eleven (โลโก้ 7-Eleven) ทันที พร้อม cluster (รวมกลุ่ม) เมื่อซูมออก
- ขนาดโลโก้หมุดจะปรับเล็ก/ใหญ่อัตโนมัติตามระดับการซูม
- ปุ่ม **🏪 ร้าน 7-Eleven** ในแถบเมนูด้านซ้าย ใช้เปิด/ปิดการแสดงหมุดร้าน 7-Eleven ทั้งหมดได้ (จำค่าไว้ใน browser)
- ช่องค้นหา (**⌕ ค้นหาชื่อจุด...**) ใช้ค้นหาได้ทั้งจุดที่ผู้ใช้ปักเองและชื่อ/ที่อยู่ร้าน 7-Eleven พร้อมกัน — พิมพ์คำบางส่วนได้ (เช่น "ขอนแก่น", "บางปลาม้า") ระบบจะกรองและแสดงเฉพาะจุดที่ตรงคำค้นให้อัตโนมัติ แม้ปุ่มเปิด/ปิดร้าน 7-Eleven จะปิดอยู่ก็ตาม
- คลิกหมุดร้าน 7-Eleven เพื่อดูชื่อ/ที่อยู่ และลิงก์นำทางผ่าน Google Maps
- ไฟล์โลโก้ `7-11-logo.png` ต้องอยู่โฟลเดอร์เดียวกับ `index.html`

เวอร์ชันนี้แก้โครงสร้างระบบใหม่ตามที่ขอ โดยเอา Google Places search ออกทั้งหมด

## สิ่งที่มี
- ปุ่ม `◎` ด้านขวาล่าง สำหรับซูมไปตำแหน่ง GPS ปัจจุบัน
- ไม่มีช่องค้นหา Google Maps
- ค้นหาจุดที่ปักด้วย **ชื่อจุด / ที่อยู่ / รายละเอียด / คนปัก**
- ตารางจุดเปิด/ปิดได้ และกดแถวแล้วพาไปยังหมุดทันที
- ตารางแสดง **ชื่อคนปัก**
- popup ของหมุดแสดง **ชื่อคนปัก**
- เปลี่ยนสีหมุด
- เลือกไอคอนหมุด หรืออัปโหลดรูปเป็นหมุด
- แก้ไข/ลบหมุด
- Realtime เห็นจุดของคนอื่นในห้อง
- ต้อง Login ด้วย email/password
- ตั้งชื่อ user และแก้ชื่อได้ตลอด
- Supabase Auth จะคง session ไว้ ไม่ต้อง login ใหม่ทุกครั้งบนอุปกรณ์เดิม
- บันทึกห้องไว้ในบัญชี user ได้ไม่จำกัด
- ครั้งต่อไปกดห้องที่บันทึกไว้เพื่อเข้าได้เลย โดยไม่ต้องเก็บรหัสห้องจริงไว้ใน browser
- ข้อมูลห้องที่บันทึกผูกกับ email/user ใน Supabase
- RLS จำกัดการอ่าน/เขียนหมุดตามสมาชิกห้อง

## สำคัญ: ต้องรัน SQL ใหม่
ใช่ครับ **ต้องอัปเดต SQL** เพราะของเดิมยังไม่มีระบบ `room_members` และ `saved_rooms` รวมถึงยังใช้ anon + header รหัสห้องในการ RLS

ให้เปิด Supabase Dashboard > SQL Editor แล้วรัน `supabase.sql` ใน ZIP นี้

> ถ้าฐานข้อมูลเดิมมีข้อมูลอยู่ SQL นี้ไม่ลบหมุดเดิม แต่ก่อนรัน production ควร backup ไว้ก่อน

## Supabase Auth
ไปที่ Supabase Dashboard > Authentication > Providers > Email แล้วเปิด Email provider

ถ้าเปิด Email confirmation:
1. สมัครด้วย email/password
2. ระบบจะส่งอีเมลยืนยัน
3. กดยืนยันแล้วกลับมา login

ถ้าไม่ต้องการขั้นตอนยืนยันอีเมล สามารถปิด Confirm email ใน Supabase Auth settings ได้

## config.js
ต้องมี:
- SUPABASE_URL
- SUPABASE_ANON_KEY
- ESRI_API_KEY (สำหรับแผนที่ภาพดาวเทียม)

ถ้า ESRI key ไม่ได้ตั้งไว้ แผนที่อาจไม่แสดงภาพดาวเทียม แต่ไม่เกี่ยวกับสิทธิ์การปักหมุด

## ทำไมของเดิมปักจุดไม่ได้
โค้ดเดิมใช้ RLS ที่ตรวจ `x-room-passcode` จาก request header ซึ่งเป็นวิธีที่เปราะและทำให้การปัก/Realtime ติดปัญหาได้ง่ายเมื่อ client/auth เปลี่ยน

v3 เปลี่ยนเป็น:
`Email login -> room_join -> room_members -> RLS -> pins`

ดังนั้นเมื่อเข้าห้องสำเร็จ บัญชี user จะมีสิทธิ์ของห้องนั้น และปักจุดได้จริงผ่าน RLS

## เรื่องรหัสห้อง
คนแรกที่เข้าชื่อห้องใหม่จะเป็นคนตั้งรหัส
คนอื่นต้องใช้รหัสนั้นเพื่อเข้าครั้งแรก
หลังจาก user เคยเข้าห้องแล้ว สามารถกดห้องจาก "ห้องที่บันทึกไว้" เพื่อเข้าได้โดยไม่ต้องพิมพ์รหัสซ้ำ

ระบบไม่ได้เก็บรหัสห้องจริงไว้ใน `saved_rooms`

## รูปภาพหมุด
รูปจะถูกย่อและเก็บเป็น data URL ใน `pins.icon_img`
เหมาะกับรูปขนาดเล็กจำนวนไม่มาก หากอนาคตมีรูปจำนวนมาก แนะนำย้ายรูปไป Supabase Storage แล้วเก็บ URL แทน
