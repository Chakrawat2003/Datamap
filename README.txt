PinMap — แก้ไข 7-Eleven + Mobile

1. นำไฟล์ทั้ง 4 ไฟล์ในโฟลเดอร์นี้ไปไว้โฟลเดอร์เดียวกับ config.js และ seven11-data.js เดิม
2. ใช้ index.html, app.js, style.css ชุดนี้แทนไฟล์เดิม
3. ต้องวาง 7-11-logo.png ไว้โฟลเดอร์เดียวกับ index.html
4. จุด 7-Eleven เดิมกด "แก้ไข" แล้วเปลี่ยนชื่อ/ที่อยู่/คำอธิบาย/สีขอบโลโก้ได้
5. สีโลโก้ที่เลือกได้: เขียว, แดง, ฟ้า, เหลือง
6. การแก้ไขจุด 7-Eleven เดิมยังเก็บใน localStorage ของเบราว์เซอร์ตามโครงสร้างเดิม
7. เมนูมือถือมีปุ่ม X ที่กด/แตะได้ และแตะพื้นหลังเพื่อปิดได้
